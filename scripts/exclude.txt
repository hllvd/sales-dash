#   - Lines starting with # are comments and are ignored.
#   - Empty lines are ignored.
#   - Each pattern is an ERE matched case-sensitively against the full line.
#
# Examples:
#   >>> Step.*OK          # suppress test step OK lines containing "error" words
#   Error: test expectation  # suppress a specific known benign message
